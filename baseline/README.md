## 复现

```bash
npm run baseline                 # 全部 13 张，并重写 SHA256SUMS
ONLY=V03 npm run baseline        # 单张调试（不更新 SHA256SUMS）
CHROME_PATH=... npm run baseline # 自定义 Chrome 路径
```

- 要求 Node 22+（内置 `fetch` / `WebSocket`）与本机 Chrome；**零第三方依赖**，无需 `npm install`。
- `tools/capture-baseline.mjs` 自启静态服务器（`127.0.0.1:8791`）和无头 Chrome（CDP `9334`），结束自动关闭；端口被占用时需先释放。
- 所有场景状态仅通过 DOM 点击、合成键盘事件、DOM 注入达成，**不修改任何游戏源码**。

## 确定性控制

| 手段 | 作用 |
| --- | --- |
| `Math.random` 换成固定 LCG，开局前 `__resetRandom()` | 方块序列与颜色不随加载期音频噪声的随机调用次数漂移 |
| `Date.now` 固定 | 时间显示稳定 |
| ≥400 ms 的 `setInterval` 改为 `2147483647` | 自动下落不触发，方块停在出生位 |
| 注入 `animation:none; transition:none` | 极光 / 脉动 / 过渡停到初始态 |
| 固定视口 + `deviceScaleFactor=1` + SwiftShader | 渲染尺寸与后端固定 |

**验证结果**：同一场景连续捕获两次，SHA-256 完全一致，像素差异 `0 / 1,024,000`。修复前两次哈希不一致，根因是 CSS 动画漂移 + 开局前随机数序列被音频噪声消耗偏移。

```bash
cd baseline && sha256sum -c SHA256SUMS   # 本次 13/13 OK
```

回归时重跑 `npm run baseline`，用 `git diff -- baseline/SHA256SUMS` 判断哪些场景发生变化。校验清单中的文件名相对于 `baseline/` 目录，须在该目录内执行。

## 已知限制

1. **V09 是 DOM 注入态**（固定得分 42 / 存活 01:23），不是真实 game over；真实触发需堆叠到顶，无法稳定复现。
2. **移动场景为模拟态**：通过 `body.is-touch` + 隐藏 `#desktop-tips` 触发，不是真机触摸设备；`@media (pointer: coarse)` 的原生行为未覆盖。
3. **软件渲染**：使用 SwiftShader，与真机 GPU 在抗锯齿 / 色彩上可能有差异；跨 Chrome 版本、跨机器不保证字节级一致，`SHA256SUMS` 仅在同一环境有效。
4. **不覆盖动态视觉**：基线中 CSS 动画被禁用，极光漂移、消行脉动、落子白闪等需要视频或逐帧基线，不在本批范围。
5. 音频听感、真实触控、真手柄、iOS 套壳均未由基线验证。

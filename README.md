## 一、游戏简介

TESSERACT 是一款运行在浏览器中的 3D 空间俄罗斯方块。它在经典"堆叠—填满—消除"的核心循环之上，把棋盘从平面拓展为 `8 × 16 × 8` 的三维网格，并引入 **三轴自由旋转** 与 **三方向直线消除**，让每一次落子都变成对空间感的挑战。

**一句话定位：** 一款把俄罗斯方块从二维平面推进到三维空间的脑力游戏。

| 项目 | 内容 |

| 类型 | 3D 益智 / 空间消除 / 休闲 |

| 是否联网 | 否，纯本地运行（依赖已本地化至 `vendor/`） |

## 三、核心玩法

- 方块从顶部中央生成，在三维网格中向下坠落。
- 玩家在方块落地前，可以沿 X 轴或 Z 轴平移，并绕 X / Y / Z 三轴旋转，调整方块的朝向与位置。
- 方块落底后固定为已占用格子。
- 当某一方向上的整条直线被填满时，该直线上的所有方块被消除，上方方块受重力影响下落。
- 消除后可能引发连锁消除，连锁次数越多，得分倍率越高。
- 当新方块出生位置被已有方块占据时，游戏结束。

## 四、特色机制详解

### 1. 三轴空间旋转

经典俄罗斯方块只能绕一个轴（垂直于屏幕的轴）旋转。本作允许方块绕 X / Y / Z 三个世界轴分别旋转 90°：

- **绕 Y 轴旋转**：水平转向，类似经典俄罗斯方块。
- **绕 X 轴旋转**：前后翻转，方块会"立起来"或"倒下去"。
- **绕 Z 轴旋转**：左右翻转，方块在竖直平面内翻滚。

旋转时以形状包围盒中心为轴心，并带有踢墙机制（尝试 ±1 格偏移与抬升），在狭窄空间也能完成旋转。旋转后若形状发生重叠或数量不一致，则自动取消本次旋转。

### 2. 三方向直线消除

消除不局限于传统的一行。以下三种直线填满均可触发消除：

- **沿 X 轴**（固定 Y 与 Z）：横向一整排。
- **沿 Z 轴**（固定 X 与 Y）：纵深一整列。
- **沿 Y 轴**（固定 X 与 Z）：竖直一整根。

这使玩家的策略从"填平面"升级为"填空间"，可以在三个维度上同时布局。

### 3. 重力压实与连锁消除

消除发生后，每个 `(X, Z)` 竖直柱上的剩余方块会向下压实，填补空洞。压实可能再次构成完整直线，触发连锁消除：

- 第 1 次消除：得分 × 1
- 第 2 次连锁：得分 × 2
- 第 3 次连锁：得分 × 3
- ……以此类推，最多循环 30 次安全上限。

### 4. 落点虚影（Ghost Piece）

当前方块正下方会以半透明虚影显示其**落底后的位置**，帮助玩家在三维空间中预判落点。虚影随方块的平移与旋转实时更新；当方块已贴底时，虚影与实体重合。

由于三维视角下判断落点最困难，落点虚影是读图的关键辅助。

### 5. 消层反馈（Juice）

方块被消除时触发即时反馈：**被消格闪白 + 彩色碎片向四周飞散（带重力与旋转）**，并伴随随连锁数升调的**音效**（Web Audio，无需外部音频文件）。当单次落子同时消除多个轴向的层（连锁 ≥ 2 或多格同消）时，额外播放一次全场微闪，强化「多轴同消」的爽感。所有特效均为场景内临时对象，消层后自动回收，不影响后续方块。

## 五、难度系统

| 难度 | 下落方式 | 起始间隔 | 最快间隔 | 加速系数 |
| --- | --- | --- | --- | --- |
| 简单 | 不自动下落，空中悬停 | — | — | — |
| 中等 | 自动下落 | 1200 ms | 400 ms | 0.12 / 分 |
| 困难 | 自动下落 | 820 ms | 220 ms | 0.20 / 分 |

- **简单模式**：方块悬停在空中，完全由玩家控制。玩家可以慢慢调整位置与朝向，按下"落底"按钮后才确认落下。适合新手熟悉三轴旋转与三方向消除。
- **中等 / 困难模式**：方块自动下落，速度随分数提高而加快（存在下限，不会无限加速）。适合追求节奏与高分。

## 六、操作方式

### 桌面端（键盘）

| 操作 | 按键 |
| --- | --- |
| 沿 X 轴移动 | ← / → |
| 沿 Z 轴移动 | ↑ / ↓ |
| 绕 Y 轴旋转 | Q / E |
| 绕 X 轴旋转 | W / S |
| 绕 Z 轴旋转 | A / D |
| 落底 / 确认 | 空格 |
| 暂停 / 继续 | P |
| 返回菜单 | Esc |
| 重新开始 | R |
| 回正视角（一键回到默认等距视角） | C |

### 移动端（虚拟按键）

- **第一排**：`−X` `+X` `−Z` `+Z` 四个平移按钮，支持长按连续移动。
- **第二排**：`X ↻` `Y ↻` `Z ↻` 三个旋转按钮，点击一次旋转 90°。
- **第二排末尾**：`⤓` 落底按钮；`回正` 按钮一键回到默认等距视角，自由旋转/缩放迷失方向时快速复位。
- 落底虚影：当前方块正下方会显示半透明落点预览，随操作实时更新。

## 七、方向指示设计

由于玩家可以自由旋转视角，传统的"左 / 右 / 前 / 后"按钮在 3D 空间会产生歧义。本作采用 **"轴名 + 世界轴 Gizmo"** 的交互方案：

- 按钮直接标注轴名：平移按钮为 `−X / +X / −Z / +Z`，旋转按钮为 `X / Y / Z`，不再使用拟人化方向词。
- 右上角世界轴 Gizmo：一个独立渲染的小型三轴指示器，随主相机实时旋转。X 轴红、Y 轴绿、Z 轴蓝，正端为实心箭头，负端为半透明箭头。
- 按下高亮联动：按下任意轴按钮时，Gizmo 上对应的轴端会放大并提高不透明度，持续约 340 ms，形成"我按的就是这根轴"的即时反馈。

玩家只需观察 Gizmo 判断轴朝向，即可在任意视角下明确知道该按哪个按钮。

## 八、界面布局

- **左上角**：分数卡片（大号数字）、时间、当前难度标签；下方为「菜单」「暂停」按钮。
- **右上角**：「下一个」方块预览卡片；下方为世界轴 Gizmo。
- **底部（移动端）**：两排虚拟操作按钮。
- **中央**：3D 游戏区域，无任何遮挡。
- **覆盖层**：开始界面（难度选择）、暂停界面、结束界面（最终得分 + 再开一局）。

## 九、计分规则

- 每消除一个方块的基础分：**10 分**。
- 连锁加成：第 N 次连锁时，该次消除得分乘以 N。
- 公式：`本次得分 = 消除方块数 × 10 × 连锁次数`。
- 分数累计显示在左上角，游戏结束时展示最终得分。

## 十、胜负判定

- 无胜利终点，为无尽模式。
- **失败条件**：新方块从顶部中央生成时，其任意一格与已固定方块重叠或超出顶部边界，游戏立即结束。
- 衡量成功的标准：存活时间、最终分数、连锁消除次数。

## 十一、技术实现简述

| 模块 | 说明 |
| --- | --- |
| 渲染 | Three.js WebGL 渲染器，主场景与 Gizmo 使用独立渲染器 |
| 相机 | PerspectiveCamera + OrbitControls，支持拖拽旋转与滚轮缩放，移动端根据屏幕宽高比自动调整 FOV 与机位 |
| 场景 | 8×16×8 网格，线框边界盒 + 半透明底部平面 |
| 方块 | 共享 BoxGeometry 与 EdgesGeometry，材质按颜色缓存复用 |
| 状态管理 | Map 存储已占用格子（键为 x,y,z），当前方块与下一方块独立维护 |
| 旋转算法 | 以包围盒中心为原点做 90° 矩阵旋转，取整去重后做局部坐标归一化，配合踢墙偏移表 |
| 消除算法 | 三方向线性扫描 → 标记删除 → 竖直柱重力压实 → 循环检测连锁 |
| 性能 | 几何体与材质复用、Gizmo 高亮角度阈值去抖、暂停时清除定时器 |
| 依赖管理 | Three.js 已本地化至 `vendor/`（`vendor/build/three.module.js` 与 `vendor/jsm/`），离线可运行 |

## 十二、设计理念

经典俄罗斯方块的核心乐趣在于"在有限空间里做最优决策"。TESSERACT 试图把这个决策空间从二维扩展到三维，同时不牺牲操作的确定性：

- 三轴旋转带来更丰富的形状变换，但也带来方向感混乱的风险；
- 三方向消除带来更自由的布局策略，但也提高了空间想象门槛；
- 轴名按钮 + 世界轴 Gizmo 的设计，正是为了在"自由视角"与"明确操作"之间取得平衡。

简单模式的存在，让这款游戏既是休闲消除游戏，也可以当作一个三维空间感的练习场。

## 运行方式

本项目使用 ES Module + importmap，**需通过 HTTP 服务器打开**（直接用 `file://` 双击打开会因模块跨域限制无法加载）。

任选一种本地静态服务器：

```bash
# Python 3
python3 -m http.server 8000

# 或 Node
npx serve .
```

然后浏览器访问 `http://localhost:8000/` 即可。

也可直接部署到 GitHub Pages / 任意静态托管，无需任何构建步骤。

## English

TESSERACT is a browser-based 3D spatial Tetris. It extends the classic "stack–fill–clear" loop onto an `8 × 16 × 8` 3D grid, adding **tri-axis rotation** (X / Y / Z) and **three-direction line clearing**.

- **Tech:** Three.js (WebGL), vanilla JavaScript, HTML/CSS. Fully offline (Three.js vendored under `vendor/`).
- **Modes:** Endless, three difficulties (Easy / Normal / Hard).
- **Run:** Serve over HTTP (ES modules + importmap). e.g. `python3 -m http.server`, then open `http://localhost:8000/`.
- **iOS:** A native iOS build via Capacitor is planned (see "iOS App 路线" above). This repo currently ships the Web version only.

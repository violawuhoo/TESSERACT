## 倒金字塔重构（扁平化 + 取消 R + 首块消失 + 推翻斜滑重力，已实施，未提交）
- 用户三条需求：①金字塔更扁、口更大；②取消 R 重启快捷键；③第一个进入的方块总会消失。
- **推翻上一版的"斜向滑动重力"**（重要）：仿真证明它把所有方块吸成中心一根尖塔——漏斗底 4×4 的外圈永远填不到 → 整层永远填不满 → 一局 14 块 game over、**0 次消除**。改为与立方体完全同一套规则：`pyrCompact()` 按 (x,z) 列竖直压实到该列最低有效格（即停在可见台阶上）。仿真验证不变量：无悬空（下方必有块或为容器外）、不出界、数量守恒；40 局平均 105 块 / 8.4 次消除（立方体基线 75 块 / 1.7 次）。⇒ 教训：漏斗形状下任何"向中心聚合"的重力都会破坏层消除的前提（层要填满就必须铺开，不能收敛）。
- 尺寸改为**由台阶推导**，不再用 round 连续收缩（旧公式会让 y=0..2 完全没有有效格）：
  `PYR_MIN_HW=2 / PYR_TOP_HW=floor(min(COLS,DEPTH)/2)=4 / PYR_TIER_H=3 / PYR_ROWS=3*(4-2+1)=9`，`pyrHW(y)=min(TOP, MIN+floor(y/TIER_H))`。
  层宽：底口 4×4（16 格，y0-2）→ 中段 6×6（36 格，y3-5）→ 上口 8×8（64 格，y6-8）。共 9 层（立方体 16 层），开口做到网格最大值 → 满足"更扁、口更大"。
  `PYR_MIN_CLEAR = (PYR_MIN_HW*2)^2 = 16`：最小的层也有 16 格，保证**任何一层都填得满、都能被消除**，同时单块（4 格）不可能填满一层 → 顺带根治了"第一个方块消失"。
- **容器线框改为与判定逐格一致**（原来是 ConeGeometry 光滑圆锥，比真实可落区域宽，是"看不懂规则"的来源）：`buildPyramidWire()` 直接用 `pyrHW(y)` 生成阶梯结构；分两个 LineSegments——台阶结构 opacity 0.45、每层分隔淡线 0.14。校验：每层线框包围盒与有效格包围盒完全一致。

## 九层逐级加宽金字塔：规则仿真结论（未改代码）
- 用户新需求：每层逐级加宽、底层 1 格、共 9 层、每层虚线框标可落范围；玩法要"落下去更难"。用户选定：刚性不动（不被新方块压塌）、9×9 足迹、无地基层全部可消。先做仿真。
- 几何（已验证）：足迹 9×9，`w(y)=y+1`，`lo(y)=4-floor((w-1)/2)`，`hi=lo+w-1`；层范围 y0:{4} y1:{4,5} y2:{3..5} y3:{3..6} y4:{2..6} y5:{2..7} y6:{1..7} y7:{1..8} y8:{0..8}（严格嵌套）。**偶数层中心偏 0.5 格**（8×8 网格中心 3.5 只能做偶数宽度，做 1 格必须整数中心）。
- 仿真结论（随机 20~30 局 + 启发式选点 10~15 局）：
  1. **刚性不动不可行**：边缘列只有 1 格深（外圈只在 y=8 存在），方块落边缘即锁在顶层且无法再下沉 → 外圈灌满后可用面积逐圈收缩 → **随机 27 块必死**，会玩也仅 53~69 块、留 37 死格。压实恰好靠"把方块送进更深的内圈"维持游戏。
  2. **整层消除 + 嵌套层 = 单层传送带**：任何一层消掉后上方整体下沉，该层立刻被重新填满 → 只有最低那个可消层在工作。地基 0 层→只有 y0 消（8.6 次/局，每次 1 格）；地基 y0→只有 y1 消（7 次）；地基 y0-2→只有 y3 消（6.5 次，85 块）。上面层永远攒不满。
  3. **层内按行消除 + 逐列压实** 是唯一跑得通的组合：162 块 / 93 次消除 / 447 格 / 0 死格（随机）；151 块（会玩）。地基 y0-2 时反而近乎无限（896 块）。
- 结论：用户选的"刚性 + 全部可消（整层）"三件套互相冲突，需要重选；唯一正常的是"行消除 + 保留压实"。待用户决策后再动 `index.html`。

## 难度旋钮仿真（用户问"怎么样增加难度"，未改代码）
- 基线：9 层 1→9 + 行消 + 逐列压实 = **141~162 块**/局（立方体基线 75 块）。
- **实测无效的旋钮**（重要，避免重复试错）：
  - 锁定后不压实（仅消除后压实）→ **600 块跑满上限，更宽松**（延迟压实反而整合得更好）。
  - 完全不压实 → 200 块 + 43 死格（更乱、不更短）。
  - 行消门槛 minLen=2/3/4/6 → 166/210/251/256 块，**反而更宽松**：小层填满后变成实心大平板，上层行更好填。
  - 仅水平旋转（禁 X/Z 轴）→ 166 块，无效。
  - 加层数 11/13/15 → 293/300+/300+，**越大越宽松**。
- **有效的旋钮**：
  - **层数**（最强，近似每层翻倍）：5 层 20 块 / 6 层 41 / **7 层 73（≈立方体 75）** / 8 层 104 / 9 层 152。
  - **方块格数**：8 种平面 5 格块 → 152 降到 **111**（-27%）。
  - **下落速度**：唯一不碰几何的旋钮（未量化，定性）。
- **过头的旋钮**：加 3D 竖块（tripod / 竖 L / 竖 I4）→ 三轴旋转下 **10 块**就死，仅水平旋转 3 块，不能用。
- ⇒ 结论：9 层 1→9 这个形状决定了"天生宽松"，规则层已无空间；难度只能靠 ①降层数 或 ②5 格方块 或 ③提速。待用户选。
